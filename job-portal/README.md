# JobTrack — Job Portal & Application Tracker

A full-stack web application to organize job applications and track career opportunities.

## Features
- Dashboard with application statistics
- Add, edit, and delete job applications
- Track Applied, Interview, Offer, Rejected, and Withdrawn statuses
- Search by company, job title, and location
- Filter applications by status
- Store application details using SQLite
- Record salary, job links, interview dates, and notes
- Responsive user interface

## Technology Stack
- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## Run Locally

1. Install Python.
2. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000` in your browser.
