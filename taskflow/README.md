# TaskFlow — Productivity Dashboard

TaskFlow is a task management web application built using Python, Flask, SQLite, HTML, and CSS.

## Features
- Add tasks with High, Medium, and Low priorities
- Mark tasks as completed or pending
- Delete tasks
- Search and filter tasks
- Track progress and task statistics
- Save tasks in an SQLite database

## Technologies
- Python
- Flask
- SQLite
- HTML and CSS
- Gunicorn

## Run Locally
Install dependencies:

`pip install -r requirements.txt`

Start the application:

`python app.py`

Open `http://127.0.0.1:5000` in your browser.
